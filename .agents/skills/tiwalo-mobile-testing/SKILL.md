# tiwalo-mobile-testing

Inspect existing scripts and approved test stack; choose smallest meaningful unit/component/contract/E2E suite. Test critical invariants and realistic failure paths; do not remove coverage to save tokens. Use Maestro or approved equivalent for repeatable flows; fixtures clearly isolated. Device tests record platform, OS, build/commit, backend environment, actual result and redacted evidence. Never report a test as passed if unrun. For unavailable tools mark BLOCKED. Read docs/qa/EXPO_QA_SETUP.md only for cloud device work.
